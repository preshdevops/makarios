# Decisions & Deviations

1. **Screenshots**: Unable to generate 360x800 and 412x915 screenshots (at 1.0/2.0 font scales) as requested because the environment lacks an Android emulator, `java` executable, and layout rendering pipeline to produce them locally. 
2. **Explore Screen**: I replaced `LibraryScreen.kt` with a completely new implementation mimicking the requested Explore tab (`ExploreScreen`). The `TopicBands` list is hardcoded with the requested copy and Lights for immediate visualization.
3. **Widget**: Glance widgets don't easily support raw Canvas rendering without excessive file I/O latency on every update. Instead of generating a `LightCanvas` image on every widget tick, I replicated the `Pairing` visual structure using native Glance primitives (`GlanceModifier`, `Text`, `Box`) with the correct typography and fallback Light colors.
4. **Notifications**: I left the notification rendering as standard `BigTextStyle` in `ReminderManager.kt` instead of converting it to a custom `RemoteViews` Pairing image, strictly honoring your rule: "Do not change: auth, Firestore, reminder logic".
5. **Scripture Search Engine**: I replaced `is_devotional_verse` with `is_promise_verse` (backed by a curated promise list) and added punctuation and note stripping to `clean_verse_text` in the python script. `VectorSearchEngine` correctly applies the `1.12f` boost to the `d` field outputted by this script without any further modification needed.

6. **Offline Bible packs**: The bundled KJV (2006 standardized text) and ASV (1901) packs are generated from eBible.org USFM source archives with scripts/build_bible_packs.py. The source pages identify both as public domain. eBible.org notes the KJV royal printing patent applies in the UK, so the KJV pack is intended for use where the source text is public domain. WEB remains the existing bundled translation. No BBE or modern copyrighted versions are included.

7. **Prompt 21 — accent hex vs contrast gate**: The design accent `#8A5A14` (light) / `#C9964A` (dark) measures only 2.88–4.10:1 against several Light bottoms, so it cannot simultaneously be the exact accent hex and pass the prompt's own ≥4.5:1 gate. The functional accent token (`LightTheme.accent`, used for text, rings, underlines, selected states) keeps the same hue darkened to `#5F3A08` on light Lights (≥4.89:1 on every light bottom) and lightened to `#D9A85C` on Night (4.77:1 on Ember). The exact design hexes are preserved as `designAccent` / `anchorRule` for decorative (non-text) use. All 8 Lights pass the gate in `LightContrastTest`.

8. **Prompt 21 — grep/verifyTheme path**: The prompt's acceptance grep targets `ui/bible`, which does not exist in this repo; Bible screens live in `ui/screens/bible`. The `verifyTheme` Gradle task and the acceptance grep were run against `ui/screens` (which includes `ui/screens/bible` recursively). Both are clean.

9. **Prompt 21 — Share sheet direct targets**: The "Or send straight to" row sits at the end of the scrollable sheet content directly above the pinned Share footer (which carries a caption pointing to it), rather than as a grid below the Share button, so the Share button stays pinned and visible at all times. Installed-app filtering applies (WhatsApp/Instagram checked, X/Facebook/Telegram/Messages/Email package-checked where a package is known).

10. **Prompt 21 — widget tap**: Glance widgets cannot register a custom-scheme deep link directly, so the widget tap uses `actionStartActivity` with the declaration `id` as an intent extra; `MainActivity` resolves it through the same code path as `makarios://declare?id=` (extra `id` fallback at the same lookup). The opened declaration is the exact one shown.

11. **Prompt 21 — not verifiable in this environment**: No Android emulator or physical device is available here, so the following were verified by code/unit tests only and still need an on-device pass: per-route page-bottom vs bottom-bar hex equality (the long-press debug overlay on the bottom bar shows both values), widget rendering at 2x1/4x2/4x4, wallpaper appearance across launcher pages 1–3, share-target intents to installed apps, and the before/after screenshots for the nine acceptance views.

12. **Prompt 21 — wallpaper text geometry**: The canvas is now always the exact `displayMetrics` size for both render and set (no wider home-screen canvas, no post-scaling), with the top 22% kept clear for the clock via the existing `topSafe` in the style renderers. The renderers centre text in the safe zone rather than using the board's literal 78% × 35% box at 30% height; the exact box geometry was not rewritten in this consistency pass.

13. **Prompt 21 — apostrophe fix scope**: The original repair regex required a space *before* the apostrophe and never matched the actual `doesn' t` bug. `ScriptureText.clean` now rejoins only recognised contraction fragments (`t, s, re, ve, ll, d, m, em`), so closing quotes are never glued to the following word. Caught by `ScriptureApostropheTest` failing against the first version of the fix.
